# NLP Low-Resource Classification: Comparative Analysis

## 1. Project Overview

This repository provides the comparative analysis of three low-resource text classification experiments:

* **AG News** — 4-class news topic classification
* **DBpedia** — 14-class ontology classification
* **IMDb 50K** — binary sentiment classification

The three projects follow the same progressive experimental framework, from classical NLP representations to sentence and word embeddings.

This repository brings their results together to analyze how the different approaches behave across datasets and training set sizes.

---

# 2. Analysis

The main analysis is contained in:

```text
analysis.ipynb
```

The notebook:

* loads the results produced by the three dataset-specific projects,
* combines the experimental results,
* compares performance across datasets,
* analyzes the effect of training set size,
* compares classical NLP and embedding-based approaches,
* produces the final comparative visualizations.

The analysis focuses primarily on **Macro F1**, while also considering Accuracy and computational cost.

---

# 3. Embedding Comparison

The repository also contains:

```text
compare_embeddings.py
```

This script provides a focused comparison of the embedding experiments:

* **V6.1** — Sentence Embeddings + LinearSVC
* **V6.2** — Sentence Embeddings + L2 normalization
* **V6.3** — Sentence Embeddings + Nearest Centroid
* **V7.1** — GloVe 100d + Mean Pooling
* **V7.2** — GloVe 100d + TF-IDF Weighted Mean

It can be run on the results directory of each dataset:

```bash
python compare_embeddings.py <dataset_directory>
```

The script:

* loads the V6 and V7 embedding results,
* displays the combined results,
* generates an embedding performance comparison plot,
* saves the combined results as CSV and HTML files.

# 4. Experimental Framework

The three datasets follow the same general progression:

```text
Baseline
   |
V1 - Stop Words
   |
V2 - N-grams
   |
V3 - Stemming
   |
V4 - Lemmatization
   |
V5 - Hyperparameter Optimization
   |
V6 - Sentence Embeddings
   |
V7 - Word Embeddings + Pooling
```

Training subsets are evaluated at different sizes to study performance under low-resource conditions.
